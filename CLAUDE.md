# Project rules

## Commits

These apply to every commit in this project:

- Never add a `Co-Authored-By` trailer, a "Generated with Claude Code" line, a Claude-Session
  link or any other mention of Claude or Anthropic to commit messages, PR descriptions or code
  comments.
- Commit only as the repo's configured Git user. Never use `--author`, and never change
  `git config user.name` or `user.email`.
- Before every commit, show the full commit message to the user.
